# Question-2-RA-Assignment


## Assignment Overview

This assignment identifies and ranks the 20 largest environmental startups in India and investigates patent records associated with these startups using WIPO PATENTSCOPE.

The project covers two main components: startup identification and ranking, followed by patent data collection, matching, and verification.

📊 [**Basic Startup-Level Spreadsheet (Excel)**](./Basic%20Startup%20level%20spreadsheet.xlsx)

## 2. Patent Data Collection and Matching

### 2.1 Consolidated Raw WIPO Data and Search Log

📊 [**WIPO Raw Data and Search Log (Excel)**](./wipo%20raw%20data.xlsx)

This workbook contains the consolidated patent records downloaded from WIPO PATENTSCOPE and the search log documenting the search terms, outcomes, and records retrieved for the 20 selected startups.

Patent records were retrieved for four startups. For the remaining 16 startups, no matching records were found under the search strategy employed, including searches using alternative company names.

### 2.2 Matched and Merged Patent Data

📊 [**Matched and Merged Data (Excel)**](./matched%20and%20meged%20data.xlsx)

This workbook contains the candidate patent records examined for matching with the selected startups, along with the available startup information and supporting verification evidence.

The matching process considered company names, founder and inventor names, company addresses, business descriptions, and available patent publication information.

### 2.3 Matching Process Description

📄 [**Matching Process Description (PDF)**](./Matching%20Process%20Description.pdf)

This document explains the procedure used to assess potential matches between patent records and the selected startups, including the matching criteria, verification approach, and limitations.

## 3. Assignment Workflow

1. Identify environmental startups in India.
2. Apply the selected ranking methodology to obtain the final list of 20 startups.
3. Compile the startup-level information.
4. Search WIPO PATENTSCOPE using company names and alternative names.
5. Download and consolidate the available patent records.
6. Cross-check candidate patent records with supplementary company information.
7. Prepare the matched dataset and document the matching process.

## 4. Important Note

The absence of a matching result in WIPO PATENTSCOPE does not necessarily mean that a startup has never filed or obtained a patent. Similarly, a retrieved record is not automatically considered a confirmed match; its association with the startup must be assessed using the available evidence.
